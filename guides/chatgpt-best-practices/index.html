Choose the right intelligence level

The menu is an intelligence setting—not simply a speed control.

Start with Instant

It is fast, capable and appropriate for most normal Vanilla Rentals tasks.

Move up with purpose

Use Medium or High when extra reasoning is likely to materially improve the answer.

Return when finished

Switch back to Instant after the complex task so the higher allowance is not used unnecessarily.

3

When higher intelligence makes sense

Choose the lowest level that comfortably handles the work.

Medium

Moderately complex document reviews, workflow planning, comparisons, prompt refinement or a problem that Instant has not handled well.

High

Difficult business analysis, technical work, complex process design or multi-step problem solving.

Extra High / Pro

Reserve for genuinely demanding work where maximum depth is important. These should not be everyday defaults.

Remember: a higher setting does not automatically produce a better answer. For many daily tasks, Instant provides the same useful outcome faster and with lower usage.

Understand the 5-hour and weekly limits

These meters help you plan heavier agentic work. They are not a countdown on ordinary Chat conversations.

NewDo not panic when you see these meters.

The Usage screen shown here says the allowance is shared across Codex, Work, Workspace Agents and ChatGPT for Excel. Regular Chat conversations are not included in this particular meter. Features and limits may vary by plan and workspace.

Where to find it

  1. Open your profile menu in ChatGPT.
  2. Select Settings.
  3. Open Usage or Usage Limits (the wording may vary by version).
  4. Review both the 5-hour and weekly meters, credits, and any reset option shown.
Getting low? Keep routine work in normal Chat or Instant. Reserve Work, Codex and heavier reasoning for tasks where the extra capability genuinely matters.
What this meter covers: the screen shown says usage is shared across Codex, Work, Workspace Agents and ChatGPT for Excel. It does not include ordinary ChatGPT conversations. Availability can vary by plan and app version.

About an available Full reset

If your Usage page offers a Full reset, read the label carefully before applying it. The screenshot shows that a reset can cover the weekly limit, the 5-hour limit, or both, and that the option can have an expiry date.

Using an available reset consumes it. Do not assume every account has the same reset options.

Vanilla Rentals guidance: save the Full reset for urgent, genuinely complex work. Do not use it simply to continue running everyday tasks on higher intelligence settings.

When does usage reset?

Normal weekly reset

The shared allowance resets automatically when the current weekly usage period ends. You do not need to press anything.

How long will I wait?

Wait for whatever time remains in the current weekly period. Use the exact reset date and time shown on the Usage page or warning banner rather than assuming midnight or a billing date.

Need access sooner?

If an eligible Full reset is available, applying it refreshes the relevant allowance immediately and consumes that one banked reset.

Use Analytics to understand activity

Analytics is a practical usage view—not a performance score and not an invoice.

Usage history

See when plan usage and credits were consumed across agentic products. Switch between the available time ranges and product or model views.

Product activity

Compare turns and, where relevant, lines of code by model or by product surface.

Tool activity

See which plugins and skills were used. This helps explain which workflows contributed to recent activity.

Tokens by model

Review input, output and cached-token patterns. Similar-looking tasks can use different amounts depending on context, model and reasoning.

How to use it: look for patterns before a large task, compare the 7-day and 30-day views where available, and allow for reporting delays. Use the Usage page for the current limit; use Analytics to understand the pattern behind it.

Manage ChatGPT storage

Uploaded and generated files can remain in Library, so deleting an old chat may not free the saved-file storage.

Keep storage under control

  1. Open Settings > Storage or use the Storage control in Library.
  2. Open Files or Images to find large or unneeded items.
  3. Download anything that must be retained, then delete duplicates and obsolete files from Library.
  4. Review Recently deleted where available if you need to restore an item or permanently free space sooner.
Good habit: reuse a file already in Library or link the approved Drive source instead of repeatedly uploading the same large PDF or image set.
Important: removing the chat alone does not necessarily remove its saved Library file. Connected Drive items remain managed in Google Drive.

Use Cloud Browser safely

Cloud Browser is a separate remote browser used by ChatGPT Work for supported website tasks. It does not inherit your device browser's tabs, passwords, cookies or existing sign-ins.

What the controls mean

Default permissions

Always ask pauses for each new site. Auto approve lets ChatGPT assess the URL and asks when it appears unsafe. Avoid an unrestricted setting for routine staff use.

Site permissions

Add a site-specific allow or block rule when an approved website needs different treatment from the default.

Browser data

Clear cookies and site data if the wrong account is remembered, sign-in loops occur, or a shared session should be removed. Clearing it signs you out.

Sign-in and approval

Use the secure sign-in prompt for passwords and two-factor codes. Review the address, screenshots and any confirmation before a consequential action.

Vanilla Rentals rule: only use Cloud Browser for authorised work. Never paste passwords, security codes or payment details into the chat. Stop if the wrong site or account appears, and check important results before relying on them.

Common questions

The practical answers staff are most likely to need.

Shared agentic usage

The Usage Limits screenshot tracks the shared pool used by Codex, Work, Workspace Agents and ChatGPT for Excel. Larger, longer and more complex tasks can use more of this allowance.

Ordinary ChatGPT conversations

Normal ChatGPT chats, images, uploads and voice can have separate limits and reset periods. They are not measured by the weekly meter shown in this guide.

Where do I find the exact reset time?

Check Profile > Settings > Usage or read the limit warning. The date and time shown in your account is the best source because limits and interfaces can vary by plan.

What if Instant gives a weak answer?

First make the request clearer and include the missing context. If the task is genuinely complex or the improved prompt still falls short, move to Medium and try again.

Does every task use the same amount?

No. Usage can vary with the model, task complexity, duration, amount of context and where the task runs. A short request generally uses less than a long, multi-step job.

What happens when the limit is reached?

An active Codex task may be allowed to finish. Afterward, the available options may include waiting for the displayed reset, applying an available Full reset, adding credits or changing plan.

Should I use the Full reset as soon as it appears?

No. Keep it for urgent work that genuinely needs the shared allowance. It is consumed when used and expires on the date shown if it is not used.

What if I cannot see Usage in Settings?

The Usage page and reset options depend on the plan, product and rollout. Look for a usage summary in the profile menu or a limit banner. If neither appears, ask the account owner or manager.

Can ChatGPT write a social media post?

Yes. Use ChatGPT for the wording and ideas, then use Canva or approved design software for the finished branded visual.

Can I paste tenant or owner information?

Only use company information in line with Vanilla Rentals privacy and security policies. Remove unnecessary personal details, and never paste passwords, access codes, payment information or identity documents unless an approved process specifically requires it.

Eight golden rules

Keep these as your everyday default.

  1. Keep ChatGPT on Instant for normal daily work.
  2. Use higher intelligence only when deeper reasoning has a clear benefit.
  3. Switch back to Instant when the complex task is complete.
  4. Check Settings > Usage before large agentic tasks.
  5. Use Analytics to understand patterns, not to judge performance.
  6. Remove obsolete files from Library rather than only deleting chats.
  7. Use Cloud Browser only for authorised work and review sensitive steps.
