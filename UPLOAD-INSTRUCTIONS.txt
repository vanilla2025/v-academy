V | Academy 3.10.4 - NEW badge on individual resource cards

WHAT THIS PATCH DOES
- Adds a NEW badge directly to newly released Tool / Agent cards.
- RentHistory Agent will show NEW inside Tools & Workflows while it is unseen.
- The Tools & Workflows sidebar NEW badge and the RentHistory card NEW badge use the same seen state.
- Opening RentHistory Agent clears both badges for that user/browser.
- The card badge does not blink; the sidebar badge keeps the existing gentle pulse.

FILES TO REPLACE
Copy these files into the matching folders in your existing v-academy repository and choose Replace when prompted:

1. js/app.js
2. js/config.js
3. css/academy.css

DO NOT delete or replace the rest of your site.
No Apps Script or Google Sheet change is required.

DEPLOYMENT
1. Copy the three files above into your local GitHub v-academy folder.
2. Commit and push to main.
3. Wait for Cloudflare Pages to deploy.
4. Refresh the site with Ctrl + F5.
5. Confirm the sidebar shows Version 3.10.4.

TEST
- Use a browser/profile that has not yet opened RentHistory Agent.
- Tools & Workflows should show NEW in the sidebar.
- Open Tools & Workflows. The RentHistory Agent card should also show NEW.
- Click Open agent guide.
- Return to Tools & Workflows. Both the sidebar and card NEW badges should be gone.
